# vacancies-analysis
Вебзастосунок, що збирає та структурує доступні вакансії, формує агреговану аналітику і типові профілі вимог для певних спеціалізації та рівня, сортує вакансії за відповідністю до цих типових профілів. Має на меті зрозуміти, які технічні навички найчастіше зустрічаються на ринку відповідно до заданих критеріїв. Початковими джерелами обрано Djinni та Jobico, що відкрито надають доступ до вакансій через xml-фіди: https://jobico.io/api/feeds/jobs.xml та https://djinni.co/jobs/rss/.
## Технологічний стек
Frontend – React + Vite
Backend – Node.js, NestJS
База даних – PostgreSQL
ORM та міграції – Prisma
## Структура проєкту
Проєкт організовано як монорепозиторій з окремим frontend і backend застосунками, які взаємодіють через http api. Backend реалізується як модульний моноліт з наступними модулями: 
-	market – формування та отримання профілів вимог, сортування вакансій за наближеністю до них
-	analytics – загальна ринкова аналітика
-	ingestion – імпорт, нормалізація і дедублікація даних з джерел
-	scheduled-jobs – регулярні запити для отримання оновленої інформації про вакансії
-	prisma – доступ до бази даних PostgreSQL.
