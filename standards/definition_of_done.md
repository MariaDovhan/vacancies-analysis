## вимоги при яких задача вважається виконаною
- Усі критерії прийняття зі spec.md виконано
- Код відповідає прийнятим правилам форматування та стилю
- Лінтер і статичний аналіз проходять без помилок
- Усі передбаченні до завдання тести проходять
- Зміни перевірені командами з Makefile
- Архітектурно важливі рішення задокументовано в adrs\\{назва рішення}
- Зміни зафіксовано в GitHub
- Сформовано DEFENSE.md до завдання
